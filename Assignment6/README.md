# Assignment 6: Arrays: Reverse and Duplicates

## 1. Experiment Title
Arrays: Reverse and Duplicates

## 2. Aim
Reverse an array, find its smallest value, and check for repeated values.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)
- Terminal / Command Prompt to compile and run Java programs
- Git and GitHub for version control and submission

## 4. Theory
Reverse traversal starts at length-1; minimum tracking stores value and index; nested loops can detect duplicates.

## 5. Algorithm / Procedure (question-wise)

### Question 1: Print {10,20,30,40,50} in reverse, one per line.

**Procedure:** Loop backward from the final index to zero.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
50
40
30
20
10
```

### Question 2: Find the smallest value and index in {2,5,1,8,3,4}.

**Procedure:** Track the minimum and its index while traversing the array.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
Smallest: 1 at index 2
```

### Question 3: Check {4,9,2,9,7} for a repeated value using nested loops.

**Procedure:** Compare each element with subsequent elements; print the duplicate if found.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
Repeated value: 9
```
