# Assignment 11: Bubble Sort and Selection Sort

## 1. Experiment Title
Bubble Sort and Selection Sort

## 2. Aim
Sort arrays using bubble sort and selection sort, and count swaps.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)
- Terminal / Command Prompt to compile and run Java programs
- Git and GitHub for version control and submission

## 4. Theory
Bubble sort swaps adjacent out-of-order values; selection sort selects the smallest remaining element. Count actual exchanges.

## 5. Algorithm / Procedure (question-wise)

### Question 1: Bubble-sort {5,1,4,2,8} and print the sorted array.

**Procedure:** Compare adjacent values in passes and swap when needed.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
Sorted: [1, 2, 4, 5, 8]
```

### Question 2: Selection-sort {64,25,12,22,11}.

**Procedure:** Find the minimum in each unsorted suffix and swap it into place.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
Sorted: [11, 12, 22, 25, 64]
```

### Question 3: Bubble-sort {5,1,4,2,8} and count swaps.

**Procedure:** Increment the counter only when two adjacent values exchange places.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
Swaps: 4
```
