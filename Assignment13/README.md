# Assignment 13: Strings: Methods and Palindromes

## 1. Experiment Title
Strings: Methods and Palindromes

## 2. Aim
Use String methods, reverse a word, check a palindrome and print substrings.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)
- Terminal / Command Prompt to compile and run Java programs
- Git and GitHub for version control and submission

## 4. Theory
String methods include length(), indexOf(), toUpperCase(), charAt() and substring(). A palindrome reads the same forward and backward.

## 5. Algorithm / Procedure (question-wise)

### Question 1: For Programming, print length, first g position and uppercase form.

**Procedure:** Call length(), indexOf('g') and toUpperCase().

**Input:** No runtime input. Word Programming.

**Expected output:**
```text
Length: 11
Position of g: 3
Upper case: PROGRAMMING
```

### Question 2: Reverse Java using charAt() and + in a loop.

**Procedure:** Traverse characters from last to first and append them to a result string.

**Input:** No runtime input. Word Java.

**Expected output:**
```text
Reversed: avaJ
```

### Question 3: Check whether racecar is a palindrome.

**Procedure:** Compare mirrored characters or compare the word with its reverse.

**Input:** No runtime input. Word racecar.

**Expected output:**
```text
racecar is a palindrome
```

### Question 4: Print all substrings of abc, by starting letter and shortest to longest.

**Procedure:** Use nested loops over start and end positions and call substring(start,end).

**Input:** No runtime input. Word abc.

**Expected output:**
```text
a
ab
abc
b
bc
c
```
