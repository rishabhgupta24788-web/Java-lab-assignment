# Assignment 5: Arrays: Traversal and Counting

## 1. Experiment Title
Arrays: Traversal and Counting

## 2. Aim
Create arrays, visit every element, and add or count values.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)
- Terminal / Command Prompt to compile and run Java programs

## 4. Theory
Arrays store same-type values; indexes start at zero and length gives the element count.

## 5. Algorithm / Procedure (question-wise)

### Question 1: For arr={3,4,5}, print each element as Index i: value.

**Procedure:** Loop from 0 to arr.length-1 and print index and value.

**Input:** No runtime input. arr={3,4,5}.

**Expected output:**
```text
Index 0: 3
Index 1: 4
Index 2: 5
```

### Question 2: For {12,45,7,33,21}, find sum and largest.

**Procedure:** Traverse once, accumulating the sum and updating the maximum.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
Sum: 118
Largest: 45
```

### Question 3: For {5,12,2,14,7}, count values greater than 10.

**Procedure:** Increment a counter for every element above 10.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
Count greater than 10: 2
```
