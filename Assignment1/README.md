# Assignment 1: Hello World, Variables and Arithmetic

## 1. Experiment Title
Hello World, Variables and Arithmetic

## 2. Aim
Print text, store values in variables and calculate with arithmetic operators.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)
- Terminal / Command Prompt to compile and run Java programs
- Git and GitHub for version control and submission

## 4. Theory
`println`, primitive/reference types, variables, `final`, arithmetic operators and integer division.

## 5. Algorithm / Procedure (question-wise)

### Question 1: Print Hello World and Welcome to Java on separate lines.

**Procedure:** Use two `System.out.println()` statements in order.

**Input:** No runtime input. Both messages are fixed.

**Expected output:**
```text
Hello World
Welcome to Java
```

### Question 2: Declare roll=101, percentage=84.5, section='B', name="Asha" and print labelled values.

**Procedure:** Declare the required variables and print each label and value on its own line.

**Input:** No runtime input. Use the specified values.

**Expected output:**
```text
Roll: 101
Percentage: 84.5
Section: B
Name: Asha
```

### Question 3: For a=17 and b=5, print sum, difference, product, quotient and remainder.

**Procedure:** Use +, -, *, / and % and print each result with its label.

**Input:** No runtime input. a=17, b=5.

**Expected output:**
```text
Sum: 22
Difference: 12
Product: 85
Quotient: 3
Remainder: 2
```

### Question 4: Declare final PI=3.14 and calculate area and perimeter for radius 7.

**Procedure:** Use area=PI*r*r and perimeter=2*PI*r; print the formatted results.

**Input:** No runtime input. PI=3.14, radius=7.

**Expected output:**
```text
Area: 153.86
Perimeter: 43.96
```
