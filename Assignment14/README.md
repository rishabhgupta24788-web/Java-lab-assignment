# Assignment 14: Characters: Counting and Positions

## 1. Experiment Title
Characters: Counting and Positions

## 2. Aim
Use charAt to count vowels and a letter, and print each letter's position.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)
- Terminal / Command Prompt to compile and run Java programs
- Git and GitHub for version control and submission

## 4. Theory
Traverse a string using charAt(i); indexes begin at zero. Use counters for matching characters.

## 5. Algorithm / Procedure (question-wise)

### Question 1: Count vowels in programming.

**Procedure:** Loop over characters and increment the counter for a, e, i, o or u.

**Input:** No runtime input. s="programming".

**Expected output:**
```text
Vowels: 3
```

### Question 2: Count occurrences of g in programming.

**Procedure:** Loop through s and count characters equal to 'g'.

**Input:** No runtime input. s="programming".

**Expected output:**
```text
Count of g: 2
```

### Question 3: Print each character of hello with its zero-based position.

**Procedure:** Loop over indexes and print index, colon, space and character.

**Input:** No runtime input. s="hello".

**Expected output:**
```text
0: h
1: e
2: l
3: l
4: o
```
