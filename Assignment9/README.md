# Assignment 9: Matrices: Rows and Columns

## 1. Experiment Title
Matrices: Rows and Columns

## 2. Aim
Use nested loops to print, add and count matrix values.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)
- Terminal / Command Prompt to compile and run Java programs
- Git and GitHub for version control and submission

## 4. Theory
Matrix indexing uses row then column. Column sums keep the column fixed while traversing rows.

## 5. Algorithm / Procedure (question-wise)

### Question 1: Print first and last rows of the specified 3x3 matrix.

**Procedure:** Print row index 0 and row index length-1 with labels.

**Input:** No runtime input. Matrix rows are 1 2 3; 4 5 6; 7 8 9.

**Expected output:**
```text
First row: 1 2 3
Last row: 7 8 9
```

### Question 2: Print the sum of each column.

**Procedure:** Loop through columns and sum that column across all rows.

**Input:** No runtime input. Use the specified matrix.

**Expected output:**
```text
Column 1 sum: 12
Column 2 sum: 15
Column 3 sum: 18
```

### Question 3: Count values greater than 5 in the matrix.

**Procedure:** Use nested loops and increment a counter for each element above 5.

**Input:** No runtime input. Use the specified matrix.

**Expected output:**
```text
Values greater than 5: 4
```
