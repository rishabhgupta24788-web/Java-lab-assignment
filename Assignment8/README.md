# Assignment 8: Matrices: Transpose and Row Sums

## 1. Experiment Title
Matrices: Transpose and Row Sums

## 2. Aim
Create 2D arrays, traverse rows, transpose a matrix and calculate row sums.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)

## 4. Theory
Matrices use row and column indexes. Transpose swaps row and column positions; row sums add elements across one row.

## 5. Algorithm / Procedure (question-wise)

**Expected output:**


**Input:** No runtime input. Use the specified matrix.
