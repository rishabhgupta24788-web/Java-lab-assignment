# Assignment 12: Insertion Sort

## 1. Experiment Title
Insertion Sort

## 2. Aim
Sort arrays with insertion sort and count shifts.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)
- Terminal / Command Prompt to compile and run Java programs
- Git and GitHub for version control and submission

## 4. Theory
Insertion sort inserts each key into a sorted prefix by shifting larger preceding elements one place to the right.

## 5. Algorithm / Procedure (question-wise)

### Question 1: Insertion-sort {7,3,5,1}.

**Procedure:** For each key, shift larger preceding values right and insert the key.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
Sorted: [1, 3, 5, 7]
```

### Question 2: Insertion-sort {14,3,9,21,6}.

**Procedure:** Apply insertion sort from index 1 to the final index.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
Sorted: [3, 6, 9, 14, 21]
```

### Question 3: Insertion-sort {6,5,4,3,2,1} and count shifts.

**Procedure:** Increment the counter every time an element moves one position right.

**Input:** No runtime input. Use the given array.

**Expected output:**
```text
Shifts: 15
```
