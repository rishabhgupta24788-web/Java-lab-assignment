# Assignment 2: Decisions and Loops with Numbers

## 1. Experiment Title
Decisions and Loops with Numbers

## 2. Aim
Use if, else-if and loops to make decisions and repeat steps with whole numbers.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)
- Terminal / Command Prompt to compile and run Java programs
- Git and GitHub for version control and submission

## 4. Theory
Conditional branching, remainder, leap-year logic, loops and factorial calculation.

## 5. Algorithm / Procedure (question-wise)

### Question 1: Check whether n=27 is even or odd.

**Procedure:** Use if-else and test n % 2 == 0.

**Input:** No runtime input. n=27.

**Expected output:**
```text
27 is odd
```

### Question 2: For marks=83, print grade A for 90+, B for 75–89, otherwise C.

**Procedure:** Use an else-if ladder in descending threshold order.

**Input:** No runtime input. marks=83.

**Expected output:**
```text
Grade: B
```

### Question 3: Check whether year=2024 is a leap year.

**Procedure:** Use divisible-by-4/not-by-100 OR divisible-by-400 logic.

**Input:** No runtime input. year=2024.

**Expected output:**
```text
Leap year
```

### Question 4: Calculate factorial of 5 with a for loop.

**Procedure:** Initialize result to 1 and multiply by each integer from 1 through 5.

**Input:** No runtime input. Calculate 5!.

**Expected output:**
```text
Factorial of 5 is 120
```
