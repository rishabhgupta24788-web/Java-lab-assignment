# Assignment 10: Switch and ArrayList

## 1. Experiment Title
Switch and ArrayList

## 2. Aim
Use switch branches and store or change values in an ArrayList.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code) as the IDE/text editor (replace this with your actual IDE if different)
- Terminal / Command Prompt to compile and run Java programs
- Git and GitHub for version control and submission

## 4. Theory
Switch selects a case; ArrayList supports add, size, get, set and remove, with zero-based indexes.

## 5. Algorithm / Procedure (question-wise)

### Question 1: For day=3, print weekday names for 1, 2, 3 and Invalid day otherwise.

**Procedure:** Use switch cases 1, 2, 3 and default.

**Input:** No runtime input. day=3.

**Expected output:**
```text
Wednesday
```

### Question 2: Create ArrayList [10,20,30,40], print list, size and item at index 2.

**Procedure:** Add values, then use size() and get(2).

**Input:** No runtime input. Use the given values.

**Expected output:**
```text
[10, 20, 30, 40]
Size: 4
Item at index 2: 30
```

### Question 3: Change index 1 to 25 and remove index 3 from [10,20,30,40].

**Procedure:** Use set(1,25), remove(3), then print list and size.

**Input:** No runtime input. Start with the given list.

**Expected output:**
```text
[10, 25, 30]
Size: 3
```
