## 5. Algorithm / Procedure (question-wise)

### Question 1: Implement fact(n) and nCr(n,r); print nCr(5,2).

**Procedure:** Use factorial and nCr = n!/(r!*(n-r)!).

**Input:** No runtime input. Call nCr(5,2).

**Expected output:**
```text
5C2 = 10
```

### Question 2: Implement fact(n) and nPr(n,r); print nPr(5,2).

**Procedure:** Use factorial and nPr = n!/(n-r)!.

**Input:** No runtime input. Call nPr(5,2).

**Expected output:**
```text
5P2 = 20
```

### Question 3: Implement maxOf(a,b) and print maxOf(14,9).

**Procedure:** Return the larger integer and print it in main.

**Input:** No runtime input. Call maxOf(14,9).

**Expected output:**
```text
Larger: 14
```
